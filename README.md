# k8s-ai-troubleshooter
AI-powered Kubernetes and application troubleshooting assistant using Ollama, Qwen3, RAG, ChromaDB and Kubernetes.

# KubeSage

AI-powered Kubernetes and application troubleshooting assistant.

## Features

- Analyze Kubernetes logs
- Analyze pod events
- Diagnose CrashLoopBackOff issues
- RAG-based troubleshooting
- Source citations
- Kubernetes deployment
- Prometheus monitoring

## Tech Stack

- Ollama
- Qwen3 4B
- FastAPI
- Streamlit
- ChromaDB
- Kubernetes
- Prometheus
- Grafana
